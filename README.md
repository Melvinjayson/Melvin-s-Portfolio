# Melvin Jayson Ogbalu — portfolio

Portfolio site for a senior product designer working on complex, AI-enabled systems. Zero-dependency static build.

## Build

```bash
node scripts/build.mjs        # writes ./dist
cd dist && python3 -m http.server 8080
```

Node ≥ 20, no `npm install` needed.

## Structure

| Path | What |
|---|---|
| `src/data.mjs` | All case-study, experience, writing and venture content — single source of truth |
| `src/pages.mjs` | About, Lab, Writing, Ventures, Impact, Advisory, Contact |
| `src/diagrams.mjs` | Theme-aware explanatory SVG diagrams for flagship cases |
| `src/static/` | CSS, JS, self-hosted fonts, OG image, favicon, résumé PDF |
| `scripts/build.mjs` | Layout, home, work, case-study and résumé templates; sitemap, robots, 404, redirects |
| `legacy/` | Dexterity Lab Three.js prototype pages (kept as-is, served under `/lab/dexterity-lab/`) |
| `api/contact.js` | Vercel function for the contact form (Resend; needs `RESEND_API_KEY`) |
| `docs/` | Design system, information architecture, benchmark, QA report |

## Content integrity

Every outcome is labelled with an evidence level (`observed`, `reported`, `concept`, `none`). Do not add metrics, team sizes, dates, artefacts or client relationships that are not documented. Private evidence registers and career material are **not** stored in this public repository.

## Résumé PDF

`src/static/resume/melvin-jayson-ogbalu-resume.pdf` is generated by printing `/resume/` (A4, print stylesheet). Regenerate it whenever experience content changes.

## Deployment

- **Vercel:** `vercel.json` sets `buildCommand` and `outputDirectory: dist`; `/notebook/*` redirects to `/lab/*`.
- **GitHub Pages:** `.github/workflows/pages.yml` builds and uploads `dist` (the contact API is unavailable on Pages; email fallback is always shown).
